## Rules derived from the approved text

### 1. Egyptian present tense, not MSA

Use the `بي-` / `بـ` prefix for habitual action.

| Rejected (MSA) | Approved (Egyptian) |
|---|---|
| يفصل ويوصّل | بيفصل ويوصّل |
| يعمل | بيشتغل |
| يحوّل | بيحوّل |
| يقيس | بيقيس |
| ينتج | بيطلّع |
| يمنع | بيمنع |

### 2. Trade loanwords beat translated terms

Technicians say the loanword. Use it, and gloss it in English on first use.

| Rejected | Approved |
|---|---|
| المؤقت | التايمر (Timer) |
| ريليه الاستشعار | ريليه الحساس (Sensing Relay) |
| عنصر الاستشعار | الحساس / السنسور (Sensor) |
| نطاق التباطؤ | الهيستيريسيس (Hysteresis) |
| القاطع | البريكر (Breaker) |
| مرحل | ريليه (Relay) |

Keep the Arabic word where it is genuinely the spoken one: الكونتاكتور،
الحمل، الجهد، التيار، اللوحة، الدايرة.

### 3. Spoken question forms

| Rejected | Approved |
|---|---|
| كم الإضاءة | النور قد إيه |
| كم عمق الماء | الميّة واصلة لفين |
| هل يوجد طور مفقود | في طور ناقص ولا لأ |
| ما إذا كان | ولا لأ |

### 4. Connectives

- Use **يعني** to introduce the consequence.
- Use **لكن** rather than **أما … فـ**.
- Drop **إنه** / **إن** as sentence openers.
- Avoid **بناءً على**, **من حيث**, **وذلك**, **بما أن** — all translation tells.

### 5. Colloquial vocabulary

| Rejected | Approved |
|---|---|
| شيء / شيئًا | حاجة |
| الماء | الميّة |
| الإضاءة (as the thing you see) | النور |
| الدائرة | الدايرة |
| بقية دائرة التحكم | باقي الدايرة |
| كيف تستخدمه | تعرف تتعامل معاه |

### 6. Sentence length

Short declaratives. The approved paragraph runs 4 sentences where the rejected
one ran 4 longer, subordinated ones. If a sentence needs a comma to survive,
split it.

### 7. What does NOT change

- **Technical accuracy.** Register is the only thing being changed. A voltage,
  a formula, a terminal name and a safety rule stay exactly as they are.
- **The English version.** The client: *"النسخة الانجليزيه علميا منضبطه"* —
  the English is scientifically disciplined. Do not touch it.
- **Markdown structure.** Tables, formula blocks, numbered lists and headings
  keep their shape.
- **English glosses.** Keep `(Sensing Relay)`, `(Contact)` — the client asked
  for these explicitly and separately.

## Test for a rewritten paragraph

Read it aloud as if standing next to a technician at a panel. If any clause
would make him pause because nobody talks like that, it fails.
